# Galeria Code Studeo

Página única com sete projetos e galeria 3D horizontal. Navegue pelas setas da tela, pelas teclas direcionais, clicando nos previews laterais, arrastando com o mouse ou deslizando no celular. O carrossel faz loop do último para o primeiro e atualiza contador, progresso e endereço do projeto selecionado.

Abra `index.html` no navegador. Os previews usam os sites publicados dentro de iframes; o botão **Abrir site** abre a página selecionada em outra aba. As animações GSAP são carregadas por CDN. `prefers-reduced-motion` desativa as transições sem bloquear a navegação.

Para alterar endereços, capturas, nomes ou ordem dos sete projetos, edite `portfolio.config.js`. Não há referências aos projetos de advocacia nesta galeria.
